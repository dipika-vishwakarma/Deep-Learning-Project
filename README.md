# NLP Text Classification Using RNN

## Project Overview

This project uses Natural Language Processing (NLP) and Deep Learning to process text data and perform text classification using a Recurrent Neural Network (RNN).

## Technologies Used

* Python
* PyTorch
* Pandas, NumPy
* NLTK
* Jupyter Notebook

## Text Preprocessing

* Text cleaning
* Lowercasing
* Stopword removal
* Stemming
* Tokenization

## Workflow

1. Text preprocessing
2. Dataset and DataLoader preparation
3. RNN model building
4. Model training and testing
5. Model evaluation using accuracy
